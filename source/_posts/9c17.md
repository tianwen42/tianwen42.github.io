<h2 id="题目"><a href="#%E9%A2%98%E7%9B%AE" class="headerlink" title="题目"></a>题目</h2><ol start="342">
<li>4的幂</li>
</ol>
<p>难度：简单</p>
<p>给定一个整数，写一个函数来判断它是否是 4 的幂次方。如果是，返回 true ；否则，返回 false 。</p>
<p>整数 n 是 4 的幂次方需满足：存在整数 x 使得 n == 4<sup>x</sup></p>
<p><strong>示例 1：</strong></p>


```text
输入：n = 16
输出：true
```




<p><strong>示例 2：</strong></p>


```text
输入：n = 5
输出：false
```




<p><strong>示例 3：</strong></p>


```text
输入：n = 1
输出：true
```






<p><strong>提示：</strong></p>
<ul>
<li>-2<sup>31</sup> &lt;= n &lt;= 2<sup>31</sup> - 1</li>
</ul>
<p><strong>进阶：</strong>你能不使用循环或者递归来完成本题吗？</p>

<h2 id="解题代码"><a href="#%E8%A7%A3%E9%A2%98%E4%BB%A3%E7%A0%81" class="headerlink" title="解题代码"></a>解题代码</h2>

```cpp
 * @lc app=leetcode.cn id=342 lang=cpp

// @lc code=start
class Solution {
public:
    bool isPowerOfFour(int num) {
        return num>0 && (num == 1 ||(num%4==0 && isPowerOfFour(num/4)));
    }
};
// @lc code=end
```
