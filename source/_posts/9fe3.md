<p><strong>斐波那契数</strong> （通常用 F(n) 表示）形成的序列称为 <strong>斐波那契数列</strong> 。该数列由 0 和 1 开始，后面的每一项数字都是前面两项数字的和。也就是：</p>


```text
F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1
```




<p>给定 n ，请计算 F(n) 。</p>
<p><strong>示例 1：</strong></p>


```text
输入：n = 2
输出：1
解释：F(2) = F(1) + F(0) = 1 + 0 = 1
```




<p><strong>示例 2：</strong></p>


```text
输入：n = 3
输出：2
解释：F(3) = F(2) + F(1) = 1 + 1 = 2
```




<p><strong>示例 3：</strong></p>


```text
输入：n = 4
输出：3
解释：F(4) = F(3) + F(2) = 2 + 1 = 3
```






<p><strong>提示：</strong></p>
<ul>
<li>0 &lt;= n &lt;= 30</li>
</ul>

```python
#递归法
class Solution:
    def fib(self, n: int) -> int:
        if(n==0):return 0
        elif(n==1):return 1
        else:return self.fib(n-1)+self.fib(n-2)
```

```python
#通项法
import math

class Solution:
    def fib(self, N):
        """
        :type N: int
        :rtype: int
        """
        sqrt5=math.sqrt(5)
        return round(pow((1+sqrt5)/2,N)/sqrt5)
```
