    tips

    • 创建内存后一定记得free, malloc,free成对出现

    • 指针创建后记得要初始化

    初始化静态或全局变量不能调用函数，如

    static int *pi=malloc(sizeof(int));  //编译错误

    改为

    static int *pi;
pi = malloc(sizeof(int));
